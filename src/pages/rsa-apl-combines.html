En bref — Le RSA compte comme ressource dans le calcul de l'APL. Ce simulateur calcule le RSA, puis l'APL en tenant compte de ce RSA, pour une estimation cohérente plutôt que deux chiffres qui s'ignorent.

La CAF calcule chaque aide séparément dans ses outils officiels — ici, une seule saisie pour les deux.

📘 Pourquoi calculer les deux ensemble

Le RSA est d'abord calculé sur vos autres ressources. L'APL est ensuite calculée sur vos ressources incluant le RSA déjà perçu. Faire les deux calculs séparément sans les relier donne une image incomplète : ce simulateur enchaîne les deux dans le bon ordre.
