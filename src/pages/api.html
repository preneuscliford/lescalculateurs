Pourquoi une API LesCalculateurs ?

Depuis plusieurs années, nous maintenons des moteurs de calcul basés sur les barèmes officiels français (Code du travail, CAF, France Travail, service-public.fr), mis à jour à chaque réforme. Plutôt que de laisser ces moteurs uniquement accessibles via nos formulaires web, nous les exposons désormais en API REST pour les développeurs, fintechs, cabinets RH et outils internes qui ont besoin de ces calculs sans les réimplémenter.

Aucune IA n'intervient dans les calculs : uniquement des règles officielles codifiées et testées.

Endpoints disponibles

Endpoint Description
POST /api/v1/keys Génère une clé API gratuite (aucune clé requise)
POST /api/v1/rsa Simulation du montant de RSA
POST /api/v1/apl Simulation de l'aide au logement (APL)
POST /api/v1/are Simulation de l'allocation chômage (ARE)
POST /api/v1/retraite Âge légal de départ et trimestres requis
POST /api/v1/indemnite-licenciement Indemnité légale de licenciement
POST /api/v1/salaire-net Conversion salaire brut → net

Liste toujours à jour : GET /api/v1 (public, sans clé).

API gratuite

Générez votre clé directement ci-dessous, sans inscription ni carte bancaire. Valable 3 mois, renouvelable gratuitement à tout moment depuis cette page.

Besoin d'un usage à fort volume ? Contactez-nous.

Authentification

Générez une clé (section « Accès » ci-dessus) et envoyez-la dans l'en-tête X-API-Key de chaque requête, en POST JSON. La clé est valable 3 mois ; revenez sur cette page pour en générer une nouvelle quand elle expire. Les en-têtes de réponse X-RateLimit-Limit et X-RateLimit-Remaining indiquent votre quota.

Questions fréquentes

Comment obtenir une clé API ?

Cliquez sur « Générer ma clé API » dans la section Accès ci-dessus : une clé est générée instantanément, valable 3 mois, sans inscription ni carte bancaire.

Que se passe-t-il quand ma clé expire ?

Elle cesse simplement de fonctionner après 3 mois. Revenez sur cette page et générez-en une nouvelle en un clic, autant de fois que nécessaire.

L'API est-elle vraiment gratuite ?

Oui, l'accès actuel ne nécessite aucun paiement : générez une clé et utilisez l'API librement.

Les calculs de l'API sont-ils les mêmes que sur le site ?

Oui, exactement les mêmes moteurs, basés sur les barèmes officiels 2026. Aucune IA n'intervient dans les calculs.

Que se passe-t-il si je dépasse mon quota ?

Le quota est volontairement très large. Si vous prévoyez un usage à fort volume, contactez-nous pour qu'on l'ajuste à votre besoin.
